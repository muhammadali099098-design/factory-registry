# Реестр заводов — автономная версия

Полностью автономная программа учёта китайских OEM/ODM заводов. **Не зависит от Higgsfield** — живёт на вашем хостинге, домен покупать не нужно.

## Что умеет
- **Аккаунты**: у каждого сотрудника свой логин и пароль. Первый зарегистрированный — администратор.
- **Сброс пароля**: на экране входа есть «Забыли пароль?» — пароль сбрасывает администратор в «Админ-панели».
- **Журнал действий**: видно, кто из коллег добавил, изменил, удалил или объединил каждый завод.
- **Несколько контактов у завода**: 2–3 контакта (имя, должность, WeChat, WhatsApp, телефон, email) — списком.
- **Защита от дублей**: при похожем названии система предупреждает и предлагает объединить контакты.
- **Админ-панель**: выдавать/забирать доступ, сбрасывать пароли, назначать администратора, менять название и цвет сайта.
- **Реестр**: добавление, редактирование, удаление, поиск, фильтры, счётчик, экспорт в Excel.
- **Поля завода**: название, город, продукция, надёжность, контакты (несколько), MOQ, сроки, оплата, сертификаты, примечания.

## Хранение данных в Google-таблице (по желанию)

По умолчанию данные хранятся в локальной базе на сервере (`data/`). Можно сделать так, чтобы **все заводы жили в вашей Google-таблице** — вы видите и правите их прямо в таблице, а сайт их читает/пишет туда.

Подключение (один раз, ~5 минут):
1. Создайте Google-таблицу для заводов (или используйте существующую).
2. Откройте файл `google-sheets-appsscript.txt` из архива — это код скрипта.
3. В Google-таблице: **Расширения → Apps Script**, удалите код и вставьте этот.
4. Нажмите **Сохранить**, затем **Развернуть → Новый процесс развёртывания → Веб-приложение**.
5. «Выполнять от имени»: **Я**; «Доступ»: **Все, у кого есть ссылка**. Нажмите «Развернуть».
6. Скопируйте URL вида `https://script.google.com/macros/s/.../exec` и передайте его мне — я впишу его в сайт (переменная окружения `GOOGLE_SHEET_WEBAPP_URL`).

> Важно: в сценарии «Все, у кого есть ссылка» таблица должна быть доступна по ссылке. Скрипт работает от имени вашего аккаунта, поэтому используйте отдельную таблицу строго для реестра. Если сайт с данными нужно защитить — данные остаются в таблице, а доступ к сайту ограничен входом.

## Запуск на своём компьютере (для проверки)
> Если вы уже запускали прошлую версию и в папке `data/` есть база — удалите папку `data/` перед запуском (изменилась структура базы).
```bash
npm install
npm start
```
Откройте http://localhost:3000 — создайте администратора (первый запуск).

## Размещение в интернете (чтобы работало у всех, бесплатно)

Нужен хостинг, который умеет запускать Node.js. Два простых варианта:

### Вариант 1 — Railway (проще всего)
1. Создайте бесплатный аккаунт на https://railway.app
2. Загрузите папку с этим проектом (или подключите GitHub).
3. Railway сам определит проект Node.js. Запуск: `npm install`, затем `npm start`.
4. **Если данные в локальной базе**: добавьте переменную `DATA_DIR=/data` и подключите **Volume** на `/data` (чтобы база не стиралась при перезапуске).
5. **Если данные в Google-таблице**: добавьте переменную окружения `GOOGLE_SHEET_WEBAPP_URL` = URL вашего Apps Script. Volume не нужен.
6. Railway даст адрес вида `ваш-проект.up.railway.app` — это ссылка для сотрудников.

### Вариант 2 — Render (free tier)
1. Аккаунт на https://render.com → New → Web Service.
2. Подключите репозиторий. Build command: `npm install`. Start command: `npm start`.
3. Для локальной базы: `DATA_DIR` = `/var/data` + Disk (Volume) на `/var/data`. Для Google-таблицы: впишите `GOOGLE_SHEET_WEBAPP_URL`.
4. Render даст адрес `ваш-проект.onrender.com`.

> На идеально бесплатных тарифах диск может быть не включён. Если данные в Google-таблице — диск вообще не нужен, это удобно.

### Вариант 3 — любая машина/VPS с Node.js
Скопируйте проект, выполните `npm install && npm start` (порт из переменной `PORT`).

## Структура
- `server.js` — сервер и API (вход, пользователи, заводы, журнал, экспорт).
- `store.js` — хранилище заводов: Google-таблица (через Apps Script) или SQLite (резерв).
- `db.js` — база SQLite (пользователи, сессии, журнал, настройки).
- `google-sheets-appsscript.txt` — код скрипта для подключения Google-таблицы.
- `public/index.html` — интерфейс.
- `data/` — локальная база (если не используется Google-таблица).

## Первый вход
После запуска откройте сайт → появится форма «Создать администратора». Заполните имя, email, пароль. Затем в «Админ-панели» добавляйте сотрудников — каждый получит свой логин.
